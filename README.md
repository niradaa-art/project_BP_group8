## แผนการแบ่งงานโปรเจค

| ขั้นตอน | ผู้รับผิดชอบ | รายละเอียดงาน |
|---|---|---|
| **1. ศึกษาและทำความเข้าใจ Dataset** | ณิรดา | ศึกษาที่มาของชุดข้อมูล “รายการจัดสรรงบประมาณระดับจังหวัด ประจำปีงบประมาณ พ.ศ. 2566” ตรวจสอบจำนวนข้อมูล จำนวนคอลัมน์ และความหมายของแต่ละตัวแปร รวมถึงกำหนดขอบเขตข้อมูลที่จะใช้ในโครงงาน |
| **2. เตรียมและทำความสะอาดข้อมูล (Data Preparation)** | ณิรดา | ตรวจสอบชนิดข้อมูล Missing Values ข้อมูลซ้ำ ข้อมูลผิดรูปแบบ และค่าผิดปกติ ปรับรูปแบบข้อมูลและจัดเตรียม Dataset ให้พร้อมสำหรับนำไปใช้งาน |
| **3. สำรวจข้อมูลเบื้องต้น (Exploratory Data Analysis)** | ณิรดา | สำรวจลักษณะของข้อมูลหลังจากทำความสะอาด เช่น จำนวนจังหวัด หน่วยงาน กระทรวง แผนงาน และประเภทของงบประมาณ เพื่อทำความเข้าใจข้อมูลก่อนนำไปวิเคราะห์ |
| **4. กำหนดประเด็นและคำถามที่ต้องการศึกษา** | ธนพล | กำหนดคำถามที่ต้องการตอบจาก Dataset เช่น การกระจายงบประมาณตามจังหวัด หน่วยงาน หรือประเภทของงบประมาณ เพื่อใช้เป็นแนวทางในการวิเคราะห์ |
| **5. วิเคราะห์ข้อมูล** | ธนพล และ สุพิชชา | นำข้อมูลที่เตรียมไว้มาใช้คำนวณและสรุปข้อมูลตามประเด็นที่กำหนด เช่น การรวมงบประมาณ การเปรียบเทียบ และการจัดอันดับข้อมูล |
| **6. ออกแบบ Visualization** | สุพิชชา | เลือกประเภทกราฟให้เหมาะสมกับข้อมูลและคำถามที่ต้องการตอบ เช่น Bar Chart, Pie Chart หรือกราฟประเภทอื่น ๆ |
| **7. สร้าง Visualization** | อาทิติญา | สร้างกราฟจากข้อมูลที่ผ่านการวิเคราะห์แล้ว พร้อมปรับชื่อกราฟ แกน ตัวเลข หน่วย และรายละเอียดต่าง ๆ ให้สามารถอ่านและเข้าใจได้ง่าย |
| **8. นำข้อมูลออกไปยัง Google sheets จัดรูปแบบการนำเสนอ** | อาทิติญา | นำข้อมูลออกไปยัง Google sheets  และลำดับเนื้อหาให้เชื่อมโยงกัน |
